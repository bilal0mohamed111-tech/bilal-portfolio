# Bilal Mohammed Portfolio

Static portfolio website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example `bilal-portfolio`.
2. Upload all files in this folder to the repository root.
3. Commit to the `main` branch.
4. Open **Settings → Pages** and set **Source** to **GitHub Actions**.
5. The included workflow will deploy the site automatically after each push.

The site entry point is `index.html`. No build step or package installation is required.
